# PitWall.AI — Virtual Race Engineer

Benvenuti nella repository ufficiale di **PitWall.AI**, un assistente virtuale avanzato per il sim-racing su *Assetto Corsa Competizione* (ACC).

## Stato del Progetto
Attualmente questa repository è in fase di configurazione iniziale. 
Con l'inizio delle sessioni di sviluppo tramite **Cursor**, verranno integrati progressivamente:
- Il codice sorgente dell'MVP (Python/Streamlit).
- I moduli di analisi telemetrica (pandas).
- La logica di integrazione con gli LLM (Claude Sonnet/GPT-4o).

## Documentazione di Riferimento
Il pilastro dello sviluppo attuale è la **[Specifica Tecnica v3](PitWall_AI_Technical_Spec_v3.md)**. 
Per garantire la massima qualità del progetto in sede di revisione accademica:
1. **Integrità della Repository:** La struttura delle cartelle e i file verranno popolati seguendo rigorosamente l'architettura definita nella sezione 9 della specifica.
2. **Visualizzazione Architetturale:** Oltre alla logica testuale, verranno implementati diagrammi professionali per mappare i flussi di dati e il comportamento del Single-Agent.

## Obiettivi MVP
- **Setup Assistant:** Correzioni incrementali basate sul comportamento della vettura.
- **Gestione Risorse:** Calcolo preciso del carburante e monitoraggio usura pneumatici.
- **Performance Coaching:** Feedback qualitativo per ottimizzare traiettorie e frenate.
